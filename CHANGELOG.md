# Change Log

All notable changes to the "anypoint-monitor" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.81]

- Add **Log Search**: search Anypoint Monitoring (OpenSearch) logs with automatic CloudHub native-log fallback, single-app and all-running-apps scope, and saved searches.
- Expandable log rows with pretty-printed JSON, formatted stack traces, and extracted fields (correlationId, tracePoint, elapsed) as clickable chips.
- Time-bucketed volume histogram with error stacking and click-to-filter.
- Instant client-side filtering with match highlighting, log-level pills with live counts, removable active-filter chips, and keyboard shortcuts.
- Refreshed minimal control bar and filter component styling.
